I’d make two clarifications:

The current demo page content is fetched mostly with useEffect, not fully React Query, so SSR must refactor the data-loading boundary. The server needs to load branding/content first, pass it into React, and the client must hydrate from that same initial data.

Hydration is the real danger zone. If the server renders a full demo page but the client initially renders the current loading state, React will mismatch or wipe the useful HTML. Phase 1 should include window.__INITIAL_DATA__ or equivalent so the client’s first render matches the server render.

My recommendation: proceed with Phase 1 first.
